# データソース

「日本人はどこまで学ぶようになったか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸は e-Stat API のメタ取得・実測値で確認済み。

## 1. 結論

高校・大学進学率の長期変化と男女差、学校種別の在学者構成を、**時代・男女・学校種**の3ビューで見せる。
単位は**進学率（％）**と**在学者数（人）**。

一次ソースは文部科学省「学校基本調査」。長期の進学率は同調査の年次統計、近年の補完と在学者数は社会・人口統計体系「Ｅ　教育」（学校基本調査由来）を使う。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 学校基本調査 年次統計 進学率 | `0003147040` | 指標×年（計） | 進学率 |
| 時代（2017–2023 補完） | 社会・人口統計体系 基礎データ Ｅ教育 | `0000010105` | 指標×全国×年 | 進学率 |
| 男女 | `0003147040` + `0000010105` | 指標×性×年 | 進学率・差（女−男） |
| 学校種 | `0000010105` | 学校種×全国×年 | 在学者数・構成比 |

出典表記: 文部科学省「学校基本調査」（社会・人口統計体系経由含む、e-Stat）。

## 2. 採用データセット（メタ・実測）

### `0003147040` — 学校基本調査 （参考資料）年次統計「総括表 進学率（1948年～）」

- 軸: 表章項目(1) × 性別(3) × 学校種別・進学率(9) × 全国(1) × 年次(69: 1948–2016)
- 軸の積 1×3×9×1×69 = 1,863。実測取得は **1,236 件**（指標・性別によって開始年が異なり疎）
- 例: 大学（学部）進学率（過年度含む）は **1954年〜**
- 時間コードは `YYYY000000`（「YYYY年」）
- 値の単位は **％**
- 採用コード（cat02）:
  - `0000000010` 幼稚園就園率
  - `0000000090` 幼保連携型認定こども園就園率
  - `0000000020` 高等学校等への進学率
  - `0000000030` 高等学校等への進学率（通信制本科を除く）
  - `0000000040` 大学・短期大学等への現役進学率
  - `0000000050` 大学・短期大学等への現役進学率（通信教育部を除く）
  - `0000000060` 大学・短期大学への進学率（過年度高卒者等を含む）
  - `0000000070` 大学（学部）への進学率（過年度高卒者等を含む）
  - `0000000080` 短期大学（本科）への進学率（過年度高卒者等を含む）
- 性別（cat01）: `0000000010` 計 / `0000000020` 男 / `0000000030` 女

**制約**: e-Stat 上のこの表の最新年は **2016年**（メタ実測）。2017年以降は同系列の更新表を API 検索しても見つからなかった。

### `0000010105` — 都道府県データ 基礎データ「Ｅ　教育」

- 軸: 観測値(1) × Ｅ教育(494) × 地域(48) × 調査年(50: 1975–2024年度)
- 学校基本調査などの公表値を横断接続した指標群
- 調査年コードは `YYYY100000`（「YYYY年度」）
- 進学率の補完（全国・性）:
  - `E3801` / `E380101` / `E380102` 中学校卒業者の進学率（計/男/女）— 実測 1975–2023
  - `E4701` / `E470101` / `E470102` 高等学校卒業者の進学率（計/男/女）— 実測 2000–2023
- 在学者数（全国）:
  - `E1501` 幼稚園 / `E1701` 幼保連携型認定こども園 / `E2501` 小学校 / `E3501` 中学校
  - `E4501` 高等学校 / `E6301` 短期大学 / `E6302` 大学 / `E7201` 専修学校

### 接続ルール（2017年以降の進学率）

2016年の全国値を突き合わせた結果:

| 年次統計 (0003147040) | 2016年・計 | SSDS | 2016年・全国 | 判定 |
| --- | --- | --- | --- | --- |
| 通信制を除く高校進学率 | 96.6% | `E3801` | 96.4% | 近接。2017–2023 をこの系列に接続 |
| 大学・短大等への現役進学率 | 55.0% | `E4701` | 54.7% | 近接。2017–2023 をこの系列に接続 |
| 高等学校等への進学率（通信制含む） | 98.7% | （なし） | — | 接続しない。2016年で打ち止め |

接続年は年次統計側を優先し、**欠ける年だけ SSDS を埋める**。定義の完全一致ではないため UI 注記で明示する。

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 年次ごとの「卒業後の状況調査」表（進路別卒業者数） | 年次で表IDが分かれ、長期接続コストが高い。進学率は年次統計＋SSDSで足りる |
| `0000010205` 社会生活統計指標の `#E09401` / `#E09402` | 基礎データ `E3801`/`E4701` と同系。件数・性別は基礎データ側に揃える |
| 都道府県別進学率 | 第1版の3ビューは全国の物語に集中。地域は将来拡張 |
| 高等専門学校の在学者数 | SSDS「Ｅ教育」に対応コードが見当たらなかった |

## 4. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | rate | metrics |
| `gender.json` | metric × sex × year | rate, gap | metrics, sexes |
| `school.json` | school × year | enrollment, share | schools |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。
進学率は配信時に **0–1 の割合**へ正規化（表示は％）。

## 5. 注記（UIに短く出す）

- 進学率の定義は指標ごとに異なる（現役／過年度含む、通信制の扱い）
- 年次統計の進学率は 1948–2016。高校（通信制除く）と大学・短大現役は SSDS で 2023 まで延長
- 学校種ビューの在学者数は SSDS 経由（1975年度〜）。少子化で義務教育の人数は減り、大学は増える構図
- 短大進学率は長期で低下、大学（学部）は上昇（特に女性）

## 6. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```

`ESTAT_APP_ID` は `.env` に置く（コミットしない）。配信用 JSON は追跡する。
